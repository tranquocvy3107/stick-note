Stick Note {{version}} (Linux, no installation)

To start: run "stick-note" in this folder (in a terminal: ./stick-note).
Nothing needs to be installed.

Stick Note opens in its own window when Chrome, Chromium, Edge or Brave is
installed. Otherwise it opens in a tab of your default browser, which works too.
The program quits by itself a few minutes after you close the window.

Your notes are saved in the "data" folder next to "stick-note".
  - To move Stick Note to another computer or a USB stick, copy this whole folder.
  - To back up your notes, copy the "data" folder.

To remove Stick Note, close it and delete this folder.
